### General options

```{option} -h, --help  (default: false)
Show help message
```
```{option} -H, --help-all  (default: false)
Show full help message
```
```{option} -a, --attributes  (default: false)
List output attributes
```
```{option} -v, --version  (default: false)
Show version
```
```{option} -j, --jobs <int> (default: 4)
Number of worker jobs to use. Reconstruction uses roughly jobs - 1 threads.
```
```{option} -c, --config <string> (default: <no value>)
Configuration file
```
```{option} --trace-interval <int> (default: 10)
Interval for tracing in seconds
```
```{option} --loglevel (trace|debug|info) (default: info)
Specify loglevel
```
### Global options

```{option} --unit-scale <float> (default: 1)
Metres per input coordinate unit. All metre-based reconstruction, crop, and output parameters are converted to input coordinate units using this factor. For feet, use `0.3048`.
```
### Input options

```{option} --id-attribute <string> (default: <no value>)
Building ID attribute to be used as identifier in CityJSONSeq output.
```
```{option} --force-lod11-attribute <string> (default: <no value>)
Input attribute (boolean) to force individual buildings to always be reconstructed using simple extrusion (LoD 1.1).
```
```{option} --yoc-attribute <string> (default: <no value>)
Input attribute (integer) containing the building's year of construction. Only relevant when multiple pointclouds are provided.
```
```{option} --h-terrain-attribute <string> (default: <no value>)
Input attribute (float) with fallback terrain elevation for each building. Used in case no terrain elevation can be derived from the pointcloud. See also --h-terrain-strategy
```
```{option} --h-roof-attribute <string> (default: <no value>)
Input attribute (float) containing fallback roof height for buildings in case no roof height can be derived from the pointcloud.
```
```{option} --polygon-source-layer <string> (default: <no value>)
Select this layer name from `<polygon-source>`. By default the first layer is used.
```
```{option} --filter <string> (default: <no value>)
Specify WHERE clause in OGR SQL to select specfic features from `<polygon-source>`. See https://gdal.org/en/stable/user/ogr_sql_dialect.html#where
```
```{option} --box (xmin ymin xmax ymax) (default: <no value>)
Axis aligned bounding box specifying the region of interest. Data outside of this region will be ignored. Coordinates are in the input data's coordinate units and are not affected by `unit-scale`.
```
```{option} --srs <string> (default: <no value>)
Manually set or override Spatial Reference System for input data.
```
```{option} --bld-class <int> (default: 6)
LAS classification code that contains the building points.
```
```{option} --grnd-class <int> (default: 2)
LAS classification code that constains the ground points.
```
```{option} --[no-]skip-pc-check  (default: false)
Disable/enable check if all supplied pointcloud files exist.
```
### Crop options

```{option} --[no-]simplify  (default: true)
Simplify input rootprints to remove (nearly) duplicated vertices.
```
```{option} --ceil-point-density <float> (default: 20)
Enforce this point density ceiling (points per square metre) on each building pointcloud.
```
```{option} --cellsize <float> (default: 0.5)
Cellsize used for quick pointcloud analysis (eg. point density and nodata regions), in metres.
```
```{option} --min-building-density <float> (default: 1)
Minimum building-class point density (points/m²) below which a rootprint's pointcloud is flagged insufficient.
```
```{option} --max-nodata-fraction <float> (default: 1)
Maximum fraction of the roofprint area without pointcloud data. Above this threshold, a rootprint's pointcloud is flagged insufficient.
```
```{option} --terrain-grid-cellsize <float> (default: 10)
Cellsize used for the crop phase terrain fallback grid, in metres.
```
```{option} --terrain-grid-search-radius <int> (default: 3)
Number of terrain grid cells to search around a building when its local fallback cells do not contain terrain points.
```
```{option} --terrain-nodata-mode <string> (default: fill_small_gaps)
How missing terrain grid samples are handled during output triangulation: `complete_quads`, `local_triangles`, or `fill_small_gaps`.
```
```{option} --lod11-fallback-area <int> (default: 69000)
LoD 1.1 fallback threshold area in square metres. If the area of the roofprint is larger than this value, the building will be always be reconstructed using a LoD 1.1 extrusion.
```
```{option} --[no-]clear-insufficient  (default: true)
Do not attempt to reconstruct buildings with insufficient pointcloud data. If `--h-roof-attribute` is set, an LoD 1.1 extrusion will be performed, otherwise no 3D model will be generated.
```
```{option} --[no-]compute-pc-98p  (default: false)
Compute and output the 98th percentile of pointcloud height for each building.
```
```{option} --[no-]crop-only  (default: false)
Only perform the crop phase, do not perform reconstruction,
```
```{option} --[no-]crop-output  (default: false)
Output building pointclouds from crop phase as LAS files.
```
```{option} --[no-]crop-output-all  (default: false)
Output building pointclouds for each pointcloud. Only relevant when multiple pointclouds are provided.Implies `--crop-output`
```
```{option} --[no-]crop-rasters  (default: false)
Output rasterised pointcloud analytics from crop phase as GeoTIFF files. Implies `--crop-output`
```
```{option} --[no-]index  (default: false)
Output index.gpkg file with quick pointcloud analystics from crop phase.
```
### Reconstruction options

```{option} --[no-]lod12  (default: false)
Generate LoD 1.2 geometry.
```
```{option} --[no-]lod13  (default: false)
Generate LoD 1.3 geometry.
```
```{option} --[no-]lod22  (default: true)
Generate LoD 2.2 geometry.
```
```{option} --complexity-factor <float> (default: 0.888)
Balance between data fidelity (1) and smoothness (0).
```
```{option} --[no-]clip-terrain  (default: true)
Clip roofprints where patches of terrain points are detected.
```
```{option} --lod13-step-height <float> (default: 3)
Maximum step height dissolved during LoD 1.3 generalisation, in metres.
```
```{option} --plane-detect-k <int> (default: 15)
Neighbours used to grow planes.
```
```{option} --plane-detect-min-points <int> (default: 15)
Minimum points in a detected plane.
```
```{option} --plane-detect-epsilon <float> (default: 0.3)
Maximum plane fitting distance, in metres.
```
```{option} --h-terrain-strategy (buffer_tile|buffer_user|user) (default: buffer_tile)
Terrain elevation selection strategy.
```
```{option} --lod11-fallback-planes <int> (default: 900)
Maximum detected planes before aborting.
```
```{option} --lod11-fallback-time <int> (default: 1800000)
Deprecated and ignored. Wall-clock reconstruction limits were removed because they are nondeterministic; use max-plane-count under [reconstruction.plane-detector] instead.
```
### Output options

```{option} --[no-]tiling  (default: false)
Enable or disable output tiling.
```
```{option} --tilesize (x y) (default: [1000,1000])
Tilesize for rectangular output tiles, in metres.
```
```{option} --[no-]split-cjseq  (default: false)
Output CityJSONSequence file for each building instead of one file per tile.
```
```{option} --[no-]omit-metadata  (default: false)
Omit metadata line in CityJSONSequence output.
```
```{option} --[no-]terrain  (default: false)
Write one triangulated TINRelief feature per tile from the highest-quality pointcloud source.
```
```{option} --cj-scale (x y z) (default: [1e-04,1e-04,1e-04])
CityJSON output vertex precision, in input map units.
```
```{option} --cj-translate (x y z) (default: <no value>)
Translation applied to CityJSON output vertices, in input coordinate units. Uses dataset center by default.
```
